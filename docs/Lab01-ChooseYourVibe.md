# Choose your use case: this guide has moved

Read [all six beginner use cases](use-cases.md). **Retail is recommended first.** Each choice uses one record type, three fields, synthetic data, and the same verification loop.

Healthcare now means fictional non-clinical supply requests—not patients or health records. Finance means fictional internal office requests—not payments, investing, or approval authority.

Select a use case in the portal, then begin [Lab 00](lab-00-prerequisites.md). Changing your portal choice does not transform a generated app; use a new learner project for another attempt.

This filename remains for old bookmarks. The previous multi-system dashboards and achievement claims are not part of the core lab.
