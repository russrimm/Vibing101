# macOS setup: use the shared prerequisite lab

Follow [Lab 00: Set up your workspace](lab-00-prerequisites.md). It includes macOS and Windows instructions and uses the **GitHub Copilot desktop app**.

1. Download the app from the [official download page](https://github.com/features/ai/github-app), following your organization's installation policy.
2. Open **Applications → Utilities → Terminal** for the version checks.
3. Verify Node.js 24 LTS, npm, and Git both in your terminal and in the app's local session.
4. Create a new, empty learner folder in Finder and add it as a local project in the desktop app.
5. Check the session's actual working directory before scaffolding.

The old VS Code, Homebrew/CLI extension, MCP, and global Git setup steps have been retired. They are not prerequisites and should not be used as a fallback for unavailable desktop access.
