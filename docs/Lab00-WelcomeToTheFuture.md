# Welcome: this introduction has moved

The current course uses the **GitHub Copilot desktop app**, not an editor extension or CLI. Vibe coding means AI does much of the coding while you guide and verify it.

Start with [Lab 00: Set up your workspace](lab-00-prerequisites.md), then follow [the course index](../README.md). Allow 60–90 minutes after setup.

You will build one local, synthetic-data prototype through a small plan, scaffold, preview, one feature at a time, visible tests, and a reviewed local commit. No deployment, organizational data, custom agents, or MCP servers are required.

This filename is retained for old bookmarks. The old enterprise-build promises and editor-specific quiz are retired; they are not the current learning objectives.
